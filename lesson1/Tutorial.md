# Урок 1: Знакомство с Arduino Uno

## Плата Arduino Uno

Arduino Uno - это микроконтроллерная плата на базе ATmega328P. Она имеет следующие характеристики:
- Микроконтроллер: ATmega328P
- Напряжение работы: 5 В
- Входное напряжение (рекомендуемое): 7-12 В
- Входное напряжение (предельное): 6-20 В
- Цифровых I/O: 14 (из которых 6 могут быть использованы как ШИМ-выходы)
- Аналоговых входов: 6
- Постоянный ток на I/O: 40 мА
- Постоянный ток для 3.3V: 50 мА
- Память Flash: 32 КБ (0.5 КБ используется загрузчиком)
- SRAM: 2 КБ
- EEPROM: 1 КБ

## Распиновка Arduino Uno

### Цифровые пины (0-13):
- Пины 0 и 1: используются для передачи данных (TX/RX)
- Пины 3, 5, 6, 9, 10, 11: поддерживают ШИМ-сигнал (аналоговое значение)
- Пины с символом "~" обозначены как ШИМ-совместимые

### Аналоговые пины (A0-A5):
- Могут использоваться как аналоговые входы
- Можно использовать как цифровые I/O

## Основные функции на С++

### Функция setup()
Функция `setup()` выполняется однажды при запуске программы или перезагрузке Arduino. В ней обычно инициализируются переменные, пины ввода-вывода, библиотеки и т.д.

```cpp
void setup() {
  // Инициализация
}
```

### Функция loop()
Функция `loop()` выполняется бесконечно после завершения функции `setup()`. В ней реализуется основная логика работы программы.

```cpp
void loop() {
  // Основной код
}
```

## Основные команды

### pinMode(pin, mode)
Функция `pinMode()` устанавливает режим работы пина (вход или выход).

```cpp
pinMode(13, OUTPUT);  // Установка пина 13 как выхода
pinMode(2, INPUT);    // Установка пина 2 как входа
```

Режимы:
- `INPUT` - цифровой вход
- `OUTPUT` - цифровой выход
- `INPUT_PULLUP` - вход с подключенным внутренним подтягивающим резистором

### digitalWrite(pin, value)
Функция `digitalWrite()` устанавливает уровень на цифровом пине (HIGH или LOW).

```cpp
digitalWrite(13, HIGH);  // Устанавливаем высокий уровень на пине 13
digitalWrite(13, LOW);   // Устанавливаем низкий уровень на пине 13
```

### delay(ms)
Функция `delay()` приостанавливает выполнение программы на заданное количество миллисекунд.

```cpp
delay(1000);  // Пауза на 1000 мс (1 секунда)
```

## Пример простой программы

```cpp
// Светодиод подключен к пину 13
void setup() {
  pinMode(13, OUTPUT);  // Установка пина 13 как выхода
}

void loop() {
  digitalWrite(13, HIGH);  // Включить светодиод
  delay(1000);             // Пауза 1 секунда
  digitalWrite(13, LOW);   // Выключить светодиод
  delay(1000);             // Пауза 1 секунда
}
```
