# Урок 2: Переменные, типы данных и сигналы

## Переменные

Переменные - это именованные области памяти, используемые для хранения данных. В Arduino (на базе C++) переменные должны быть объявлены с указанием типа данных перед их использованием.

### Объявление переменных

```cpp
int age = 25;           // Целочисленная переменная
float temperature = 23.5; // Число с плавающей точкой
char letter = 'A';      // Символ
bool flag = true;       // Логическая переменная
```

## Типы данных

### Целочисленные типы
- `byte` - 8 бит, беззнаковое целое (0 до 255)
- `char` - 8 бит, знаковое целое (-128 до 127), часто используется для хранения символов
- `int` - 16 бит, знаковое целое (-32,768 до 32,767) для Arduino Uno
- `unsigned int` - 16 бит, беззнаковое целое (0 до 65,535)
- `long` - 32 бит, знаковое целое (-2,147,483,648 до 2,147,483,647)
- `unsigned long` - 32 бит, беззнаковое целое (0 до 4,294,967,295)

### Вещественные типы
- `float` - 32 бит, число с плавающей точкой, точность до 6-7 десятичных знаков
- `double` - на Arduino тот же, что и float

### Логические и символьные типы
- `bool` - 8 бит, логическое значение (true или false)
- `char` - 8 бит, символ в кодировке ASCII

## Выделение памяти

Каждый тип данных занимает определенное количество памяти в SRAM:

| Тип | Размер (байт) | Диапазон значений |
|-----|---------------|------------------|
| bool | 1 | true или false |
| byte | 1 | 0 до 255 |
| char | 1 | -128 до 127 |
| int | 2 | -32,768 до 32,767 |
| unsigned int | 2 | 0 до 65,535 |
| long | 4 | -2,147,483,648 до 2,147,483,647 |
| unsigned long | 4 | 0 до 4,294,967,295 |
| float | 4 | -3.4028235E+38 до 3.4028235E+38 |

## Аналоговый и цифровой сигнал

### Цифровой сигнал
Цифровой сигнал принимает только два дискретных значения:
- LOW (низкий уровень) - соответствует 0В (логический 0)
- HIGH (высокий уровень) - соответствует 5В (логический 1)

Цифровые сигналы используются для:
- Управления светодиодами
- Принятия решений (в условиях)
- Коммуникации по протоколам (SPI, I2C)

### Аналоговый сигнал
Аналоговый сигнал может принимать любое значение в заданном диапазоне. В Arduino Uno аналоговый сигнал может принимать значения от 0В до 5В и преобразуется в числовое значение от 0 до 1023 (10-битное разрешение).

Аналоговые сигналы используются с:
- Датчиками температуры
- Фоторезисторами
- Потенциометрами
- Датчиками давления

## Как обрабатывать аналоговый и цифровой сигнал

### Обработка цифрового сигнала
Для работы с цифровыми сигналами используются функции:
- `digitalRead(pin)` - чтение цифрового значения с пина
- `digitalWrite(pin, value)` - запись цифрового значения на пин

```cpp
int buttonPin = 2;
int ledPin = 13;

void setup() {
  pinMode(buttonPin, INPUT);
  pinMode(ledPin, OUTPUT);
}

void loop() {
  int buttonState = digitalRead(buttonPin);
  if (buttonState == HIGH) {
    digitalWrite(ledPin, HIGH);
  } else {
    digitalWrite(ledPin, LOW);
  }
}
```

### Обработка аналогового сигнала
Для работы с аналоговыми сигналами используется функция:
- `analogRead(pin)` - чтение аналогового значения (0-1023) с аналогового пина

```cpp
int sensorPin = A0;  // Аналоговый пин A0
int sensorValue = 0;

void setup() {
  Serial.begin(9600);
}

void loop() {
  sensorValue = analogRead(sensorPin);  // Считывание значения (0-1023)
  
  Serial.print("Сенсор: ");
  Serial.println(sensorValue);
  
  delay(100);
}
```

## АЦП Arduino

АЦП (аналогово-цифровой преобразователь) в Arduino Uno:
- 10-битный (значения от 0 до 1023)
- 6 каналов (пины A0-A5)
- Максимальное входное напряжение: 5 В
- Разрешение: 5 В / 1024 = ~0.0049 В (~4.9 мВ) на единицу

### Работа с АЦП

```cpp
// Преобразование аналогового значения в напряжение
int sensorValue = analogRead(A0);
float voltage = sensorValue * (5.0 / 1023.0);

// Чтение с нескольких аналоговых пинов
int sensor1 = analogRead(A0);
int sensor2 = analogRead(A1);
int sensor3 = analogRead(A2);
```

### Фильтрация аналоговых значений
Для получения более точных значений можно использовать усреднение:

```cpp
int readAnalogWithFilter(int pin) {
  long sum = 0;
  for (int i = 0; i < 10; i++) {
    sum += analogRead(pin);
    delay(1);
  }
  return sum / 10;
}
```
